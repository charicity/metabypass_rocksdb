# 索引恢复点清理与候选筛选：实现及验证

本轮实现两项索引优化：恢复点发布后异步清理旧点，以及依据候选目录中已复制的 MANIFEST 提前筛选文件。备份格式、两代已发布恢复点和 `SyncBackup` 接口未改变。

## 实现与故障边界

- 候选目录及 `LATEST` 按原持久化顺序完成后，立即更新已发布序号并唤醒同步写和 `SyncBackup`。独立 GC 线程删除退出 `LATEST` 保留集合的旧点。一个退休目录从排队到删除完成始终占用唯一 GC 槽；槽满时下一候选点在替换 `LATEST` 前等待，镜像线程仍可排空事件。正常关闭等待最终发布和 GC 完成。删除失败进入原有粘性后台错误路径，唤醒等待者并阻止后续写入。健康运行时最多同时存在两个已发布点、一个退休点和一个候选点。
- 镜像线程在固定事件边界刷新句柄，先按捕获长度复制 `CURRENT` 和其指定的 MANIFEST，并只在候选副本上执行一次 `Inspect`。据此捕获活跃 SST、所需 WAL、已关闭的 IDENTITY/OPTIONS；SST 优先硬链接，失败时复制。验证线程复用捕获的 `NativeState`，继续执行 WAL 完整记录、SST、blob 依赖、CRC 和持久化验证。未完成的 CURRENT、MANIFEST 原子组或尚未写完的 SST 延期到后续边界；MANIFEST 已引用但镜像中缺失的 SST 报损坏错误。
- 每个点保存逻辑大小，发布后不再遍历旧点目录计算 `retained_index_bytes`；已有点在打开时初始化大小。新增 `pending_gc_points`、`pending_gc_bytes`、`gc_micros`、`candidate_copied_bytes`，并在 `db_bench` 输出。退休点字节数在删除成功前保持原逻辑值；候选复制字节数只累计成功复制的长度，不计硬链接。

## Release A/B 性能

同一份 `scheduling-ab` 驱动源码分别链接基线提交 `758fbd1400826e2e7dc0452bcbe48d0631d214b9` 与当前实现的 Release 库。四种负载各运行五次、两版合计 **40/40 成功**。原始命令、输出、二进制哈希与逐次数据见 `/tmp/metabypass-gc-validation/performance-ab.json`；汇总见 `/tmp/metabypass-gc-validation/performance-summary.md`。下表均为五次中位数，百分比为当前相对基线的变化。

| 负载 | 前台耗时基线 → 当前 | 变化 | P99 基线 → 当前 | `SyncBackup` 基线 → 当前 |
|---|---:|---:|---:|---:|
| 256 次同步写 | 65,910,450 → 65,365,047 µs | -0.83% | 408,919 → 408,825 µs | 1 → 1 µs |
| 100,000 次混合写 | 8,532,804 → 8,343,094 µs | -2.22% | 40,960 → 40,526 ns | 901,019 → 867,396 µs |
| 100,000 次写、2 MiB 镜像事件队列 | 8,254,478 → 8,235,405 µs | -0.23% | 40,892 → 41,016 ns | 963,209 → 944,660 µs |
| 8,192 次写、1,024 个 SST | 87,084,839 → 84,482,000 µs | -2.99% | 206,895 → 212,373 ns | 594,497 → 493,571 µs |

同步写负载的 `SyncBackup` 数值只是全部同步写之后再次调用的时长，主要等待成本已计入前台耗时。大型 MANIFEST 负载禁用自动 compaction、每八次写显式 Flush；两版每次均产生 1,024 个 SST 和 129,437 字节的 MANIFEST。该负载最后一个恢复点的构建中位数从 337,896 降至 273,279 µs，滞后时间从 349,848 降至 284,924 µs，但前台 P99 从 206,895 增至 212,373 ns。混合写的 Close 中位数从 314,286 增至 366,897 µs，也不能概括为全面加速。

全部运行目录位于 `/tmp`，实际落在 ext4 `/dev/sdc2`、旋转设备 `/dev/sdc`。这是**同一 HDD 上的目录布局比较**，不是 SSD 索引加 HDD 数据的异构设备实验。每组只有同一主机的五个样本，小幅差异可能受运行波动影响；本结果不证明异构部署下的收益或物理空间节省。
